# 二、每日共同流程

## 平日

每人約 4～5 小時：

1. 15～20 分鐘：同步 Git、確認 API 格式
2. 3～4 小時：完成當日功能
3. 30～40 分鐘：測試、Commit、Push
4. 10 分鐘：回報完成項目與待整合問題

## 假日

每人約 2～3 小時：

1. 優先修正前一天問題
2. 完成較小功能或畫面
3. 補測試資料與文件
4. 不安排大型新功能
